# test-concurs

## Reguli de aur pentru un hackathon de 3 ore

1. **Alege un scop mic și livrabil.** În 3 ore contează un prototip care merge, nu o idee mare neterminată. Taie tot ce nu e esențial pentru demo.
2. **Împarte timpul înainte să scrii cod.** Rezervă ~30 min pentru idee și plan, ~2 ore pentru implementare și ~30 min pentru test, polish și prezentare.
3. **Arată ceva funcțional la final.** Un flux complet, chiar simplu, bate o listă de features pe jumătate gata. Pregătește demo-ul din timp, nu în ultimele minute.
